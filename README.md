# Used Bikes Data Analysis

A comprehensive data analysis project exploring patterns, trends, and insights from used bikes data.

## 📋 Project Overview

This project conducts an in-depth analysis of used bikes data, examining various attributes such as pricing, specifications, condition, and market trends. The analysis aims to uncover patterns that can help understand the used bikes market and provide insights for buyers and sellers.

## 📁 Repository Contents

- **Used_Bikes_Analysis.ipynb** - Main Jupyter Notebook containing:
  - Data loading and exploration
  - Data cleaning and preprocessing
  - Exploratory Data Analysis (EDA)
  - Statistical analysis
  - Visualizations and insights
  - Key findings and conclusions

## 🚀 Getting Started

### Prerequisites

- Python 3.7+
- Jupyter Notebook or JupyterLab
- Required Python packages (see installation section)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/shivakavali/Used_Bikes_Data_Analysis.git
cd Used_Bikes_Data_Analysis
```

2. Install required dependencies:
```bash
pip install pandas numpy matplotlib seaborn scipy scikit-learn
```

3. Launch Jupyter Notebook:
```bash
jupyter notebook
```

4. Open `Used_Bikes_Analysis.ipynb` to view and run the analysis

## 📊 Analysis Highlights

The notebook includes:

- **Data Exploration** - Understanding the structure and characteristics of the dataset
- **Data Cleaning** - Handling missing values, duplicates, and data quality issues
- **Descriptive Statistics** - Summary statistics and distributions of key variables
- **Visualizations** - Charts and plots to identify patterns and relationships
- **Correlations** - Analysis of relationships between different bike attributes
- **Market Insights** - Key findings about pricing, demand, and market trends
